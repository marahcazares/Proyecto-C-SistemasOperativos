# Proyecto-C-SistemasOperativos
Programa que carga 1,000 números desde un archivo de texto para construir un árbol en memoria. Posteriormente, recibe por entrada estándar un valor a buscar y realiza un recorrido del árbol para localizarlo, contabilizando el número de nodos visitados. Al finalizar, muestra si el nodo fue encontrado y la cantidad total de nodos revisados.
